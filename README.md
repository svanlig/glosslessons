# GLOSS Language Scraper

A personal learning project built to make accessing content from the GLOSS website easier.

This tool retrieves content in **Farsi, Turkish, and Arabic** from the GLOSS website. I created it because navigating the website and finding specific content can be cumbersome. The goal was to make the process quicker and simpler with just a click of a button.

**Purpose:** Personal use and learning.

**Note:** This is an independent personal project and is not affiliated with or endorsed by GLOSS.
